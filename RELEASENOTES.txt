[VERSION 2.2.0] - 2026-04-30 (Hybrid Mode Release)
---------------------------
UPGRADE FULL BITGET V3 & CLASSIC COMPATIBILITY

1. BITGET HYBRID ENGINE:
   - Auto-Detection: Bot mendeteksi mode akun (UTA vs Classic) secara otomatis. Jika dapet error 40084, bot langsung fallback ke endpoint Classic (Mix) tanpa intervensi user.
   - V3 UTA Support: Full migrasi ke /api/v3/ untuk akun yang sudah upgrade. Mendukung 'Preset SL/TP' saat open posisi.
   - V3 Signed Body: Memperbaiki sistem enkripsi request untuk mendukung POST body pada API V3.

2. BUG FIXES & STABILITY:
   - Restored Methods: Mengembalikan fungsi 'get_max_available' dan 'sync_state_with_exchange' yang sempat hilang.
   - Logic Sync: Standardisasi pembersihan nama symbol (BTCUSDT -> BTC) untuk akurasi sinkronisasi memori bot dengan bursa.
   - Timeout Hardening: Menaikkan timeout ke 20 detik untuk menangani koneksi internet yang tidak stabil.

3. RISK MANAGEMENT:
   - V3 Plan Orders: Menggunakan endpoint /api/v3/trade/place-plan-order untuk memasang SL/TP pengaman pada posisi yang sudah running.
   - Precision Field Mapping: Mapping harga entry menggunakan 'avgPrice' (UTA) dan 'entryPrice' (Classic) secara dinamis.

SISTEM SEKARANG MENDUKUNG SELURUH JENIS AKUN BITGET.
